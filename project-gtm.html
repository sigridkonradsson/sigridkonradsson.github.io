02 — Tracking / GTM

Mätning som faktiskt går att lita på

Roll
Tracking-ansvarig
Kontext
Eget fördjupningsprojekt
Fokus
GTM & GA4
Verktyg
GTM, GA4, dataLayer

00Sammanfattning

Uppbyggnad av ett komplett trackingupplägg i Google Tag Manager, från container och triggers till events som faktiskt går att analysera i GA4 — utan att gissa vad siffrorna betyder.

01Challenge

Klick som inte betydde något mätbart

Utgångsläget var en sajt utan strukturerad mätning: inga custom events, ingen tydlig koppling mellan klick och affärsvärde, och ingen dataLayer att bygga vidare på. Varje ny mätpunkt hade behövt byggas från grunden, en i taget.

02Approach

Bygg strukturen en gång, återanvänd den överallt

Istället för punktinsatser byggdes ett generellt dataLayer-mönster där varje klickbart element taggas med ett attribut i koden. Ett enda GTM-lyssnarupplägg kunde sedan fånga alla klick, oavsett var på sajten de skedde.

03Process

Container, triggers, variabler — i den ordningen

Arbetet gick igenom GTM-containerns uppbyggnad, definition av triggers för klick, formulärinskick, scroll depth och synlighet av element, samt variabler som plockar upp data direkt från dataLayer. Events kopplades därefter till GA4 tillsammans med ecommerce-parametrar och URL-parametrar för kampanjspårning.

04Outcome

Ett upplägg som är enkelt att bygga vidare på

Resultatet blev ett konsekvent trackingsystem där nya mätpunkter kan läggas till genom att bara märka upp ett nytt element i koden — utan att röra GTM-uppsättningen i grunden. Denna portfolio använder samma princip, se data-track-attributen i koden.

05Lärdomar

Bra tracking är ett designbeslut, inte en eftertanke

Den viktigaste lärdomen var att trackingstrukturen bör planeras i samma stund som sajten byggs — inte läggas till i efterhand. Ett konsekvent namngivet dataLayer sparar enormt mycket tid i GTM och gör analysen i GA4 mycket mer pålitlig.
